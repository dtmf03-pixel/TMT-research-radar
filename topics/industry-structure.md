# 콘텐츠 산업 구조 (엔터·미디어·게임)

> 회계 이슈는 **산업의 밸류체인(수익이 어디서 어떻게 발생하는가)**에서 나온다.
> 산업 구조를 알면 어떤 계정에 리스크가 쏠리는지 예측할 수 있다.

## 1. 엔터 밸류체인
`아티스트 발굴·육성 → 앨범/음원 제작 → 유통(음원플랫폼·음반) → 공연/MD → 팬덤플랫폼·광고`
- **회계 포인트**: 육성기 지출의 자산성, 다중 수행의무(앨범+공연+MD) 배분, 음원 판권 무형자산·내용연수, 팬덤플랫폼 구독 수익.

## 2. 미디어(방송·영화) 밸류체인
`기획 → 제작(제작비) → 편성/방영 or 개봉 → 유통(OTT·해외판매) → 부가판권`
- **회계 포인트**: 제작비 콘텐츠자산화 시점, 방영/유통 패턴 기반 상각, 흥행 부진 손상, 판권 라이선스 수익인식(접근권/사용권).

## 3. 게임 밸류체인
`개발(개발비) → 퍼블리싱/출시 → 라이브서비스(아이템 결제) → 글로벌 확장/IP 확장`
- **회계 포인트**: 개발비 자산화·상각, 아이템 결제 이연수익, 퍼블리싱 계약의 총액/순액, 글로벌 종속기업·환율.

## 4. 산업 → 계정 리스크 매핑
| 산업 | 매출 특성 | 리스크 집중 계정 |
|---|---|---|
| 엔터 | 복합·이벤트성 | 무형자산(음원·판권), 계약부채 |
| 미디어 | 프로젝트·흥행 | 콘텐츠자산, 손상 |
| 게임 | 라이브·결제 | 이연수익, 개발비, 영업권 |
| IT/플랫폼 | 중개·구독 | 총액순액, 영업권, 리스 |

## 5. 참고
